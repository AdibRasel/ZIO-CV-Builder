
# ZIO CV Builder

**A Free Online CV & Resume Builder by Rasal Hossain**

Create professional resumes effortlessly with ZIO CV Builder. Choose from beautiful CV templates, customize your personal information, preview changes in real time, and download your resume as a PDF.

🌐 **Live Demo:** https://adibrasel.github.io/RasalHossain/

---

## ✨ Features

- **Personal Mode:** Load personal CV information automatically from JSON.
- **Guest Mode:** Create a CV using your own information.
- **Multiple Templates:** Choose from five professional CV designs.
- **Live Preview:** See your CV updates instantly while editing.
- **Accent Colors:** Customize your CV with different color schemes.
- **Profile Image:** Add your personal photo to your resume.
- **Dynamic Sections:** Add multiple experiences, education records, projects, skills, languages, and certifications.
- **PDF Download:** Print or save your CV as a PDF.
- **Import & Export:** Import and export CV data in JSON format.
- **Auto Save:** Save your editing progress using browser Local Storage.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Background Animation:** Enable or disable preview animations.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/AdibRasel/RasalHossain.git
```

### 2. Open the Project

```bash
cd RasalHossain
```

### 3. Run Locally

Open `index.html` in your browser for the basic interface.

**Note:** Personal Mode loads JSON data using `fetch()`, which requires an HTTP server. You can use VS Code Live Server or another local HTTP server.

## 🌐 Deployment

This project is hosted using GitHub Pages.

**Live Website:**

https://adibrasel.github.io/RasalHossain/

To deploy your own version:

1. Fork or clone this repository.
2. Push the project files to your GitHub repository.
3. Open repository Settings.
4. Navigate to Pages.
5. Select `Deploy from a branch`.
6. Choose the `main` branch and `/ (root)` folder.
7. Save the settings.

## 🔒 Privacy

- Guest Mode stores CV data in browser Local Storage.
- Personal Mode loads the default profile from a JSON file.
- This project does not require a backend server for its core functionality.
- Publicly hosted profile JSON files can be viewed by anyone. Do not store passwords or sensitive personal information in them.
